# C++ Text RPG

## 프로젝트 소개
C++로 개발한 콘솔 기반 턴제 전투 RPG 프로젝트입니다.

플레이어가 몬스터와 전투하며 일반 공격, 스킬, 아이템을 선택해 사용하는 방식으로 구성했습니다. 몬스터와 보스 몬스터의 상속 구조를 통해 객체지향 프로그래밍의 주요 개념을 적용했습니다.

## 개발 환경
- Language: C++
- IDE: Visual Studio
- Platform: Windows
- Version Control: Git / GitHub

## 주요 기능
- 플레이어와 몬스터 간 턴제 전투
- 일반 공격 및 MP를 소모하는 스킬
- 포션을 통한 체력 회복
- 폭탄을 이용한 적 공격
- 아이템 사용 및 인벤토리 관리
- 보스 몬스터의 체력 조건에 따른 광폭화
- 플레이어나 몬스터의 체력이 0 이하가 되면 전투 종료

## 주요 구현 내용
- **상속 구조:** `Entity`를 기반으로 `Player`, `Monster`, `BossMonster` 클래스를 구성해 공통 속성과 기능을 관리
- **가상 함수와 다형성:** `attack()`을 가상 함수로 정의하고 `BossMonster`에서 재정의하여 보스만의 공격 동작 구현
- **가상 소멸자:** 기반 클래스인 `Entity`와 `Item`에 가상 소멸자를 정의하여 다형성을 사용하는 객체의 소멸 처리
- **아이템 추상화:** 추상 클래스 `Item`을 기반으로 `Potion`, `Bomb` 클래스를 구현하고 `use()`를 통해 아이템별 동작 분리
- **스마트 포인터:** `unique_ptr`를 활용해 플레이어의 인벤토리와 게임 객체의 소유권 관리
- **아이템 타입 구분:** `dynamic_cast`를 활용해 포션과 폭탄을 구분하고 대상에 맞게 사용
- **전투 관리:** `BattleManager`에서 플레이어의 행동 선택과 몬스터의 반격을 관리
- **보스 광폭화:** 보스의 체력이 100 이하인 상태에서 공격을 시도하면 광폭화 상태로 전환하고 공격력을 2배로 증가

## 개발하면서 배운 점
이번 프로젝트에서는 C++의 객체지향 프로그래밍 개념을 실제 게임 시스템에 적용해 보았습니다.

특히 상속과 가상 함수를 활용해 몬스터와 보스의 동작을 구분하고, 추상 클래스를 통해 서로 다른 아이템의 사용 방식을 통일할 수 있었습니다.

또한 `unique_ptr`를 활용하면서 객체의 소유권과 메모리 관리에 대해 이해할 수 있었습니다.
